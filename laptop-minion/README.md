# laptop-minion

Cortex laptop minion - sensor data collector for desktop activity tracking.

## Installation

```bash
pip install laptop-minion
```

Or install from source:

```bash
pip install -e .
```

## Quick Start

1. **Initialize configuration:**

```bash
laptop-minion init --broker mqtt://your-cortex-ip:1883 --token YOUR_TOKEN
```

2. **Run the minion:**

```bash
laptop-minion run --broker mqtt://your-cortex-ip:1883 --token YOUR_TOKEN
```

3. **Check status:**

```bash
laptop-minion status
```

## Configuration

Configuration is stored in `~/.config/laptop-minion/config.yaml`:

```yaml
broker_url: mqtt://192.168.1.100:1883
minion_id: <auto-generated UUID>
token: YOUR_TOKEN
batch:
  max_size: 50
  flush_interval: 30
sensors:
  screen_activity:
    enabled: true
  application_focus:
    enabled: true
  keyboard_activity:
    enabled: true
  battery:
    enabled: true
  network_status:
    enabled: true
```

## Sensors

### Screen Activity
- Screen on/off events
- Active window changes
- Idle detection

### Application Focus
- App switch events
- 5-minute usage summaries

### Keyboard Activity
- Keystroke counts (no raw keys)
- Mouse clicks and scrolls
- Active/idle time per 15-minute window

### Battery
- Level changes > 5%
- Charging started/stopped
- Low battery warnings

### Network Status
- WiFi/cellular changes
- Signal strength changes
- VPN activation

## Offline Queue

When disconnected from the MQTT broker, events are stored in SQLite and automatically flushed when connection is restored.

## Requirements

- Python 3.10+
- MQTT broker (Mosquitto recommended)
- macOS, Windows, or Linux

## Platform-Specific Notes

### macOS
Requires accessibility permissions for some sensor features.

### Windows
Requires Python with pywin32 for full sensor support.

### Linux
Requires system tools like `nmcli`, `iwctl`, or `xdotool` for full sensor support.
